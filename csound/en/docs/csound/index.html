Csound Architecture

2. CSOUND

CSOUND PROGRAM STRUCTURE

Csound instruments are created inside an orchestra, while the list of notes and performance events are specified in a score.

The standard command-line invocation syntax is:

csound -flags orchestra_file score_file

Csound compiles the orchestra, translates the score events, and executes them in temporal sequence, generating a digital audio output file (.wav or .aiff) or streaming live audio in real time.

ORCHESTRA FILE

An orchestra file consists of two primary sections:

  1. Header Section: Configures global audio rates and output parameters:

    • sr: Audio sampling rate in Hz (e.g. 44100).
    • kr: Control sampling rate in Hz (e.g. 4410).
    • ksmps: Ratio of sr / kr, defining the control period block size (e.g. 10).
    • nchnls: Number of output channels (1 = mono, 2 = stereo, 4 = quadraphonic).

  2. Instrument Blocks: Individual synthesis instruments bounded by instr and endin:

; Global Configuration Header
sr = 44100
kr = 4410
ksmps = 10
nchnls = 1

instr 1
  ; Instrument definition
  a1 oscil 10000, 440, 1
  out a1
endin

SCORE FILE

The score file contains event lines (p-fields) that generate function tables and schedule instrument note events:

  • f statements generate function tables (stored waveforms, window shapes).
  • i statements schedule instrument note events.
  • t statements alter tempo dynamically.
  • s and e statements mark sections and score completion.

Standard note parameters (p-fields):

  • p1: Instrument number.
  • p2: Start time (in seconds or beats).
  • p3: Duration (in seconds or beats).
  • p4...pn: Custom parameters passed directly to the instrument (e.g., amplitude, frequency, spatial position).
; Function Table 1: 4096-point sine wave
f 1 0 4096 10 1

; Play instrument 1 at time 0 for 2 seconds at 440 Hz
i 1 0 2 10000 440
e

VARIABLES AND CONSTANTS

Csound variables are classified by processing rate and scope:

  1. Audio variables (a- prefix): Updated at the audio rate (sr). Hold arrays of audio samples calculated across each ksmps cycle.
  2. Control variables (k- prefix): Updated at the control rate (kr). Used for envelopes, modulation signals, and time-varying parameters.
  3. Initialization variables (i- prefix): Evaluated only once at note initialization time (p2). Do not change during note execution.
  4. Global variables (ga-, gk-, gi- prefix): Accessible across all running instruments simultaneously, enabling audio bussing, effects sends, and master processing.

COMMENTS

Comments in Csound can be written using a semicolon ;:

; This is a comment in Csound
a1 oscil 1000, 440, 1 ; generate audio signal
