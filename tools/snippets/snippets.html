How to Mount a Drive with Permissions


    sudo mount -t cifs //drive/folder  /media/name -o username=xxxx,password=xxxx,uid=1000,gid=1000

Description: This command mounts an ext4 filesystem from device /dev/sdX1 to the directory /mnt/mount-point with specific user and group ownership, and file/directory permissions.
