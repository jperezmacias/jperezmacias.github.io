Embedded Systems, IoT & Hardware

IoT • Raspberry Pi

Automated Plant Irrigation & Lighting

An automated system built with a Raspberry Pi to keep houseplants alive during extended travels. Uses relay switches controlled via automated cron schedules for lighting cycles, integrated with medical-grade peristaltic dosing pumps to deliver precise water volume.

RTOS • Xenomai • C

Real-Time Control with Xenomai RTOS

A real-time networked control system implemented using the Xenomai Real-Time Operating System (RTOS) dual-kernel architecture. Developed during studies at Chalmers University of Technology, focusing on deterministic latency, packet jitter mitigation, and distributed control loops over network interfaces.

GitHub Repository →
Embedded C • Wireless Sensors

Wireless Sensor Monitor (Tietotalo)

A low-power distributed wireless sensor monitor programmed in C and deployed across the Tietotalo engineering facility at Tampere University of Technology (TUT). Gathers continuous telemetry for environmental and wireless network diagnostics.

Microcontrollers • Assembly • C

Microcontroller House Alarm with Keypad

An embedded security keypad alarm developed back in 2006 using an Intel 8051-family microcontroller. Implements matrix keypad scanning, armed/disarmed state machines, PIN authentication, and siren relay triggering with low-level register control.

GitHub Repository →

Numerical Simulation & Computational Modeling

COMSOL • Multiphysics • Electrophysiology

COMSOL Simulation of an Action Potential

A computational finite-element simulation of neuron membrane excitability developed at TUT. Implements the nonlinear FitzHugh-Nagumo mathematical model to simulate the propagation of action potentials and transmembrane ionic currents across nerve fibers.

▶ Watch Simulation Video
Python • Computer Vision

Finnish Winter Day-Night Timelapse

An automated timelapse camera capturing the progression from polar night to morning activity in Tampere (watching goods arrive at the local Sale market and the gym open at 6:00 AM). Built with a Raspberry Pi, a lightweight Python frame-capture script, and automated assembly.

Audio Servers, Software & Games

Raspberry Pi • PureData • DSP

RaspFX: PureData Web Audio Server

A collaborative media services server hosted on a home Raspberry Pi. Users could upload audio files via a web interface and process them in real-time through custom PureData digital signal processing patches. Built with Carita Logrén, Enrico Manuzzato, and Ugur Kar.

Sample test recordings: Guitar • Harpsichord • Viola

Meteor.js • JavaScript

Animals: Interactive Game for Kids

A touch-friendly educational web game designed for tablets and mobile devices. Developed in Meteor.js to create reactive, low-latency audio-visual feedback when children interact with animal characters.

Bus Ticketing System (C++ OOP)

My first comprehensive software engineering project in C++, developed alongside classmate Alberto León. Implements a multi-destination bus ticketing platform with object-oriented principles, custom linked-list data structures, and terminal interaction.
